# Cross-Validation and Hyperparameter Tuning in Machine Learning

A beginner-friendly article explaining how Cross-Validation and Hyperparameter Tuning help build reliable Machine Learning models that generalize well to unseen data.

## Topics Covered

- Introduction to Model Evaluation
- Train-Test Split
- Cross-Validation
- K-Fold Cross-Validation
- Types of Cross-Validation
  - Stratified K-Fold
  - Leave-One-Out Cross-Validation (LOOCV)
  - Time Series Cross-Validation
- Model Parameters vs Hyperparameters
- Hyperparameter Tuning
- Grid Search CV
- Randomized Search CV
- Bayesian Optimization
- Overfitting and Underfitting
- Data Leakage and Pipelines
- Nested Cross-Validation

## Key Learnings

- Understand why training accuracy alone is not enough.
- Evaluate Machine Learning models using Cross-Validation.
- Select suitable hyperparameters to improve model performance.
- Understand how to avoid data leakage during preprocessing.
- Build models that perform better on unseen data.
